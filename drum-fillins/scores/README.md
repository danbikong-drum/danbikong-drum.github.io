# 필인 파일 보관

각 필인 코드마다 하위 폴더를 만들어 MuseScore 산출물을 보관합니다.

```
scores/
  BAL-4B-M78-BUILD-TOM-Lv2/
    BAL-4B-M78-BUILD-TOM-Lv2.mscz       원본 (MuseScore)
    BAL-4B-M78-BUILD-TOM-Lv2.pdf        인쇄/다운로드용
    BAL-4B-M78-BUILD-TOM-Lv2.png        블로그 썸네일용
    BAL-4B-M78-BUILD-TOM-Lv2.mp3        미리듣기 오디오
    BAL-4B-M78-BUILD-TOM-Lv2.musicxml   재활용/편곡용
```

폴더명 = `catalog.csv`의 `code` 값과 동일하게 맞춥니다.
